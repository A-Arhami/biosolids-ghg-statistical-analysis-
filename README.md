# GHG Statistical Analysis

Python code for Pearson and Spearman correlations, polynomial and nonlinear regression, generalized additive modeling, and model evaluation in *Greenhouse Gas Emissions from Wastewater Solids Thermal Processes*.

Install dependencies with `pip install -r requirements.txt`. Place `EDA_MHF.xlsx`, `FBI_EDA.xlsx`, `FBI_Model.xlsx`, `EDA_FBI.xlsx`, and `EDA_dryer.xlsx` in the working directory, or set `DATA_DIR` to their location.

Open `GHG_Statistical_Analysis.ipynb` to run the analyses individually. Equivalent functions are provided in `GHG_Statistical_Analysis.py`. The facility datasets are not included.
